# NetNinja — 60 Second Quick Start

## Download & Run

1. **Download:** [NetNinja.ps1](https://github.com/YourUsername/NetNinja/releases/latest)
2. **Right-click** → **Run with PowerShell**
3. **Done!** 🎉

---

## First Time Setup (30 seconds)

When NetNinja starts:

1. **Auto-detect** finds your game server automatically
   - *OR manually enter IP/port in the HUD*

2. **Choose a profile:**
   - `MMO` — WoW, FFXIV, Ragnarok (2s ping)
   - `FPS` — CS2, Valorant, Apex (1s ping, full tweaks)
   - `Analysis` — Diagnostics (verbose logs)
   - `Silent` — Background only (no alerts)

3. **Apply optimizations** (optional):
   - Right-click tray icon → **Optimization Manager**
   - Select your game type → **Apply**
   - Restart recommended

---

## Controls

**Hotkeys:**
- `Ctrl+Alt+P` — Toggle HUD
- `Ctrl+Alt+O` — Overlay mode (gaming)
- `Ctrl+Alt+R` — Reset stats

**Tray Menu:**
- **Right-click** tray icon for full menu
- **Left-click** to show/hide HUD

---

## Features

- Real-time ping graph (60s / 5min / 30min / 1h)
- Rules Engine (automated actions)
- Multi-Target (ping 8 servers at once)
- Webhook alerts (Discord/Slack/Teams)
- Network optimizations (19+ tweaks)
- MTU optimizer
- DNS switcher
