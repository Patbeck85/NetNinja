  🚀 NÄCHSTE SCHRITTE
═══════════════════════════════════════════════════════════════

  1. ZIP ENTPACKEN
     → Entpacke NetNinja-v5.0-github.zip in einen Ordner

  2. SCREENSHOTS ERSTELLEN (Optional)
     → Öffne docs/SCREENSHOTS.md
     → Folge der Anleitung (8 Screenshots)
     → Ersetze die Platzhalter-Bilder

  3. GITHUB UPLOAD
     
     OPTION A — GitHub Desktop (EINFACH):
       • Öffne GITHUB_SETUP.md
       • Folge "Methode 1"
       • 5 Minuten → FERTIG ✅

     OPTION B — Setup-Git.bat (AUTOMATISCH):
       • Doppelklick auf scripts/Setup-Git.bat
       • GitHub-URL eingeben wenn gefragt
       • FERTIG ✅

     OPTION C — Command Line:
       • Öffne GITHUB_SETUP.md
       • Folge "Methode 2"
       • FERTIG ✅

  4. RELEASE ERSTELLEN (empfohlen)
     → GitHub → Releases → "Create new release"
     → Tag: v5.0.0
     → Upload: NETNINJA_v5.0.ps1 (aus outputs/)
     → Publish
